# PBS World RSS GLOBAL fixture verification

Checked 2026-10-15 against the exact [PBS NewsHour World RSS](https://www.pbs.org/newshour/feeds/rss/world). A bounded GET returned HTTP 200, `application/rss+xml`, and a 38,370-byte RSS 2.0 document. The channel was `PBS News Hour - World` with `https://www.pbs.org/newshour/world` as its link. Observed items had a PBS world-section URL, title, permalink GUID, publication date, description, categories, optional creator and media attachment. One creator named Associated Press, so a PBS feed item does not establish independent PBS reporting. These observations establish the offline fixture shape, not live reuse permission or a polling cadence.

The GLOBAL fixture parser requires the exact registered feed identity and channel, caps payloads at 128 KiB and snapshots at 50 entries, rejects DTD/entity declarations, and retains only `/newshour/world/` article paths. It stores title, official publisher URL/permalink, publication time and bounded creator. It discards descriptions, categories, media attachments and article bodies. World-section placement alone does not prove event type, international impact, original reporting or independent corroboration. Stored items remain background context unless later source-backed evidence supports more.

The registry entry is disabled by default and the feed is absent from the app's exact official HTTP allowlist. Offline scan tests trap HTTP and verify persisted background policy. Any live admission requires a separate publisher reuse and transport-policy review, source freshness and retention decision, and exact URL signoff.
