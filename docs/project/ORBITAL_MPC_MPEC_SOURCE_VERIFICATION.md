# ORBITAL MPC MPEC Source Verification

Checked 2026-10-15 against the Minor Planet Center's [MPECs API documentation](https://docs.minorplanetcenter.net/mpc-ops-docs/apis/mpecs/) and [publication guidance](https://minorplanetcenter.org/iau/services/ECS.html). The current documented endpoint is `https://data.minorplanetcenter.net/api/mpecs`, using a GET request with a JSON search body. A single exact-term researcher request for `2025-A18` returned HTTP 200, 306 bytes, and one result with `fullname`, `title`, `pubdate`, and `link`, matching the published schema. The old registry docs URL was replaced with this data endpoint.

MPECs are temporary publications and may later be corrected in permanent MPC circulars. Individual MPEC pages permit linking but restrict redistribution of their content. The fixture parser therefore stores only notice ID/title, UTC publication time, official circular link, and a no-body/no-impact framing. It requires one exact non-wildcard search term, caps results at 20, rejects non-MPC links and malformed IDs, and suppresses routine daily orbit-update titles. It never downloads or stores MPEC text, observations, orbit elements, or inferred close-approach risk. Every item remains background class.

The registry candidate remains disabled and no MPC endpoint is live allowlisted. Before live admission, define a limited set of current object terms, response-size/expiry/backoff contract, API health behavior and a reproducible query mechanism; the current general HTTP allowlist does not support GET request bodies. NEOCP, observation, orbit and observatory-code APIs remain separate verification work.
